# CS-255 System Analysis and Design

This repository contains my work for **CS-255: System Analysis and Design** at Southern New Hampshire University.

## Course Overview
In this course I learned the principles, methods, and techniques of systems development, including requirements gathering, process and object modeling, UML diagrams, and system design.
